ES MAMBO PKY — Aplikasi Pembukuan
=================================

Isi paket:
- index.html  -> aplikasi utama
- manifest.json -> agar bisa dipasang sebagai aplikasi di Android
- sw.js -> dukungan offline dasar

Cara memakai:
1. Buka index.html di browser.
2. Data tersimpan otomatis di browser/perangkat.
3. Untuk memasang seperti aplikasi Android, buka melalui alamat website/hosting HTTPS lalu pilih "Tambahkan ke layar utama" / "Install app" pada Chrome.
4. Gunakan menu Backup secara berkala untuk membuat file .json.

Fitur:
- Dashboard omzet, pengeluaran, laba bersih, dan total terjual
- Pemasukan per rasa, jumlah, harga, dan status lunas/belum
- Pengeluaran berdasarkan kategori
- Stok per rasa dan produksi
- Rekap harian
- Export rekap CSV
- Backup/import data
- Data awal diambil dari Pembukuan_Es_Mambo.xlsx yang diberikan pengguna

Catatan:
Perhitungan laba bersih aplikasi mengikuti Excel: omzet dikurangi total pengeluaran.
